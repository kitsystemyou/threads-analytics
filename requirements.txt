# Threads投稿インサイト分析ツール 要件定義

## 1. システム概要

Meta公式のThreads APIを活用し、自分自身の直近の投稿パフォーマンス（閲覧数や各種エンゲージメント）を比較・分析できるダッシュボードツール。

## 2. 機能要件

* **直近の投稿データ取得:** * Threads API (`GET /me/threads`) を利用し、自身のアカウントの直近10件の投稿データを取得する。
* 投稿の識別子（ID）および投稿テキスト（冒頭部分等）を一覧化のキーとする。


* **投稿ごとのインサイト（Metrics）取得:** * 取得した10件の各投稿IDに対し、インサイト用API (`GET /{media-id}/insights`) を実行し、以下の指標を取得する。
* 閲覧数 (views)
* いいね数 (likes)
* 返信数 (replies)
* リポスト数 (reposts)
* 引用数 (quotes)


* **エンゲージメントの算出:** * 取得した指標をもとに、投稿がどれだけ反応を得られたかを測る数値を自動計算する。
* （例）エンゲージメント率 ＝ `(いいね数 + 返信数 + リポスト数 + 引用数) ÷ 閲覧数`


* **データの可視化（UI表示）:** * 取得・計算したデータをダッシュボード画面に出力する。
* 投稿ごとのパフォーマンスを比較しやすいよう、表（データグリッド）やグラフ（棒グラフ等）を用いて描画する。



## 3. 非機能要件・システム制約

* **データ取得の安全性:** * アカウント凍結の特大リスクや保守コストの増大を避けるため、Selenium等を用いたブラウザ操作（スクレイピング）は一切使用しない。
* データの取得は完全に公式の「Threads API」に依存して行う。


* **データの取得タイミング（リアルタイム性）:**
* （履歴の蓄積が不要であるため）ユーザーがダッシュボード画面を開いた際、または画面上の「更新」ボタンを押下したタイミングでAPIへリクエストを送り、常に最新の数値を表示させる構成とする。



## 4. 画面構成イメージ

* **メインダッシュボード:**
* **直近10件のパフォーマンス比較グラフ:** 横軸を各投稿、縦軸を「閲覧数」や「エンゲージメント数」としたグラフ表示。
* **投稿詳細リスト:** 投稿テキスト、投稿日時、各種インサイト指標、エンゲージメント率が一覧で並ぶ表形式のビュー。
